The current sample team uses Claude, Codex, and ChatGPT. The shared icon registry
also supports OpenClaw, Hermes Agent, Cursor, and Grok when those agent kinds are
present in project data. Unknown kinds use a neutral bot icon, not another brand.
“Grokbok” was not verified as a distinct product and is not silently aliased.
